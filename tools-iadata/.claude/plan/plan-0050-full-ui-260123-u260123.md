# Plan 0050: Full UI Implementation Strategy

## Overview
This plan outlines the multi-iteration strategy to build the complete **Tools IADATA** Dashboard UI. It builds upon the existing Shell Layout and Backend API to deliver a fully functional "AI Data Lake" interface.

**Target Stack**:
- **Framework**: Next.js 14+ (App Router)
- **Styling**: TailwindCSS (via `globals.css` or Modules) - *Note: Project uses vanilla CSS primarily, adapting to existing patterns.*
- **Icons**: Lucide React
- **State**: React Context (for Active Environment) + Server Actions (Data Fetching).

## Iteration 1: Environment Foundation
**Goal**: Enable users to browse, select, and manage Environments. This drives the "Context" for everything else.

### 1.1 State Management (`src/context`)
- **`EnvironmentContext`**: A global provider wrapping the dashboard.
    - Stores `activeEnvironmentId` and `activeEnvironment` object.
    - Persists selection to localStorage.

### 1.2 Environment Pages (`/dashboard/environments`)
- **List View (`page.tsx`)**:
    - Grid of "Environment Cards".
    - Badge for "Owner" vs "Shared".
    - "Create New" card.
- **Create/Edit Modal**:
    - Name, Description.
    - Default Model selection (Dropdown).
- **Environment Selector (Sidebar)**:
    - Update the stub `EnvironmentSelector.tsx` to read from Context and display the active env name.

### 1.3 Server Actions (`src/actions/environments.ts`)
- `getEnvironments()`
- `createEnvironment(data)`
- `deleteEnvironment(id)`

## Iteration 2: Resources Management
**Goal**: Allow configuration of inputs (Data Sources) and tools (MCPs) for the active environment.

### 2.1 Sources UI (`/dashboard/sources`)
- **Polymorphic List**:
    - Tabbed view: "Static Sources" (Docs/Web) vs "MCP Tools" (Dynamic).
- **Data Source Editor**:
    - Type Selector (Local, Web, Drive, SharePoint).
    - **Dynamic Form**: Renders specific fields based on Type (e.g., `path` for Local, `url` for Web).
    - "Test Connection" button.
- **Indexing Status**:
    - Real-time pill (Pending/Running/Ready) sourced from `system_jobs` table.

### 2.2 MCP Editor (`/dashboard/sources?tab=mcp`)
- **Card List**: Display configured MCPs.
- **Add MCP Modal**:
    - Name, Transport Type (STDIO/SSE).
    - Command/URL input.
    - Env Vars Input (Key-Value pairs, values masked).

### 2.3 Server Actions (`src/actions/resources.ts`)
- `getSources(envId)`
- `saveSource(envId, data)`
- `getMCPs(envId)`
- `saveMCP(envId, data)`

## Iteration 3: Intelligence & Agents
**Goal**: Configure the "Brains" of the environment.

### 3.1 Agents Page (`/dashboard/agents`)
- **Master-Detail Layout**:
    - Left: List of Agents (Navigator, Architect, etc.).
    - Right: Editor Panel.
- **Agent Editor**:
    - Name, Role.
    - **System Prompt**: Large CodeMirror/Textarea input.
    - **Model Override**: Optional Dropdown to force a specific model (e.g., Omni for reasoning).
    - **Tool Selection**: Checkbox list of available MCPs to attach to this agent.

### 3.2 Server Actions (`src/actions/intelligence.ts`)
- `getAgents(envId)`
- `saveAgent(envId, data)`

## Iteration 4: The Chat Workspace
**Goal**: The primary interface for "Chatting with Data".

### 4.1 Chat Layout (`/dashboard/page.tsx` & `/dashboard/chat/[sessionId]`)
- **Three-Pane Layout**:
    - **Left (Sidebar)**: Session History (group by Date).
    - **Center (Main)**: Chat Stream.
    - **Right (Context - Collapsible)**: Source Citations / Artifacts / Agent Thoughts.

### 4.2 Chat Components
- **Message Bubble**:
    - User (Right aligned).
    - Assistant (Left aligned, Markdown rendered).
    - "Thinking" state.
- **Input Area**:
    - Textarea (Auto-resize).
    - **Agent Selector**: Dropdown to pick which Agent to talk to (defaults to "Navigator").
    - Attachment Clip (for ad-hoc uploads if supported).

### 4.3 Chat Logic (`src/hooks/useChat`)
- **Streaming**: Use `ai/react` (Vercel AI SDK) or custom fetch stream for control.
- **Persistence**: Auto-save sessions to Postgres `chat_sessions`.

## Roadmap

| 4 | **Agent Editor** | Edit Prompts/Tools | Env Context |
