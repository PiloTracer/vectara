# Feature: GPU Toggle Setting

**ID**: 0513-gpu-toggle-260125
**Status**: Implemented
**Date**: 2026-01-25

## 1. Goal
Values stability and compatibility. Allow users to toggle GPU acceleration on/off.
- **Default (CPU)**: Safe for all machines (no NVIDIA driver requirement).
- **Optional (GPU)**: Opt-in for performance.

## 2. Architecture: The "Split & Merge" Strategy

To support conditional hardware requirements without maintaining two massive duplicate files, we use **Docker Compose Overrides**.

### The Files
1.  **`docker-compose.dev.yml` (Base)**:
    - Defines all services (`back-dl`, `front-dl`, `pg-dl`, `qdrant`, `llm-dl`).
    - **Crucially**: The `llm-dl` service here has **NO** GPU reservation. It is pure CPU.
    
2.  **`docker-compose.gpu.yml` (Overlay)**:
    - Contains *only* the GPU reservation block for `llm-dl`.
    ```yaml
    services:
      llm-dl:
        deploy:
          resources:
            reservations:
              devices:
                - driver: nvidia
                  count: 1
                  capabilities: [gpu]
    ```

### How It Works (The Merge)
When the user enables GPU, we run:
```bash
docker compose -f docker-compose.dev.yml -f docker-compose.gpu.yml up
```
Docker **merges** the second file onto the first. The result in memory is a single configuration that includes the specific GPU reservation logic added to the base `llm-dl` service.

## 3. Implementation Details

### Backend (`src-tauri/src/docker.rs`)
The `start_docker` command reads the `USE_GPU` environment variable:
- **If `false`**: Runs `docker compose -f docker-compose.dev.yml up`
- **If `true`**: Runs `docker compose -f docker-compose.dev.yml -f docker-compose.gpu.yml up`

### Frontend (`Settings.tsx`)
A new checkbox "Use GPU Acceleration" toggles the `USE_GPU` variable in `.env.dev`.

## 4. Verification

### CPU Mode (Default)
1.  Set "Use GPU" to **OFF**.
2.  Restart Docker.
3.  `docker inspect iadata_llm_dev` -> `HostConfig.DeviceRequests` should be null/empty.
4.  Works on any machine.

### GPU Mode
1.  Set "Use GPU" to **ON**.
2.  Restart Docker.
3.  `docker inspect iadata_llm_dev` -> `HostConfig.DeviceRequests` should contain `nvidia`.
4.  **Requirement**: Machine must have NVIDIA GPU + Drivers + Container Toolkit.
